# ChatShare

ChatShare is a real-time messaging app that allows users to share messages, files, and media seamlessly. Built with privacy and simplicity in mind, ChatShare ensures a smooth communication experience.

## Features
- Real-time messaging
- File and media sharing
- End-to-end encryption
- Group chats
- Cross-platform support (Web, Android, iOS)
